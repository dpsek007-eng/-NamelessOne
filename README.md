# 이렘의 탑 (Tower of Irem)

멸망한 세계가 탑의 형태로 남았다.
플레이어는 그 세계 바깥의 존재이고, 탑에 갇힌 죽은 자들을 불러내 함께 오른다.

모바일 방치형 수집 RPG · Unity 6 · 1부 100층

---

## 한 줄

> 플레이어는 이렘을 **구하러** 왔다고 믿는다.
> 그런데 탑이 보낸 신호는 구조 요청이 아니었다.

## 핵심 설계

| | |
|---|---|
| **등급 = 선명도** | 강함이 아니라 "탑이 얼마나 또렷하게 기억하는가" |
| **본디** | 숨겨진 성장 한계. ★1이 10성까지 갈 수도, ★5가 6성에서 멈출 수도 |
| **확률이지 약속이 아니다** | ★1은 ★6까지 갈 확률도, 가서 좋을 확률도 낮다 (0.35%). 태생 ★4는 쉽고 싸고 강하다 (23.2%) |
| **남은 버릇 5종** | ★6 특성이 고유가 아니면 역할 하나가 묻어온다 — 막아선 자국 · 쥐던 손 · 내민 손 · 뜬 눈 · 먼저 난 발자국. 굴리지 않고 **겹친 사람들의 다수결** |
| **초점** | 선명도를 문자 그대로 그림에 건다. ★1은 얼굴이 **없는** 게 아니라 **안 맞는다**. 각성할수록 맞아 간다 |
| **초반 상한** | 지금 열려 있는 선명도는 **★6 까지**. ★7~10은 아직 쓰이지 않은 문장이다 |
| **레벨** | 상한이 **도달 최고층**. 탑을 오르면 로스터 전체가 따라 오른다 |
| **겹치기** | 잔상을 겹쳐 기억 조각을 읽는다. 조각 5개 = 성급 +1. 흡수된 잔상의 스킬 하나가 남는다 |
| **개화** | 육성 방식에 따라 다른 스킬로 갈라진다. 늦개화 재능도 있다 |
| **뜰 (0층)** | 불러낸 잔상이 사는 곳. 생전의 생업을 그대로 한다 |
| **층 공략** | 모든 층에 최소 3가지 길. 약한 캐릭터로 푸는 길에 최고 보상 |
| **고유성** | 무명 잔상은 플레이어마다 다르게 생성된다 |

**오를수록 과거로 간다.** 1층이 멸망의 날, 100층이 세계의 시작.
위로 갈수록 세계가 아름다워지고, 그럴수록 무거워진다.

## 구조

```
docs/    설계 문서 21개 — 세계관 · 시스템 · 스토리 100층 · 검증 기록
tools/   밸런스 시뮬레이터 · 외형 도구 25개 (Python)
data/    캐릭터 15명 · 층 30개 (JSON)
```

### 문서

| | |
|---|---|
| `01`~`03` | 세계관 · 캐릭터 시스템 · 뜰 |
| `04`~`08` | 본디 · 고유성 · 층 공략 · 개화 · 승급 |
| `09`~`13` | 스토리라인 · 시스템 구조 · 비트시트 · 대본 · 확장구조 |
| `14`~`16` | 1막 · 2막 · 3-4막 대본 (1~100층) |
| `17`~`21` | 편성 · 소환 · 방치와 등반 · 소실 · 페이싱 |


시뮬레이터 실행:

```bash
python3 tools/bondi_sim.py      # 본디 분포·승급 비용
python3 tools/fusion_sim.py     # 승급 경제
python3 tools/gacha_sim.py      # 소환 확률
python3 tools/summon_value.py   # 소환 1회의 값 (조각 기준)
python3 tools/trait_odds.py     # ★6 특성이 고유일 확률
python3 tools/focus_curve.py    # 초점 곡선 (얼굴이 또렷해지는 속도)
python3 tools/pacing_sim.py     # 1막 페이싱
python3 tools/shade_gen.py 10   # 무명 잔상 생성
```

외형 확인:

```bash
python3 tools/serve.py                     # 브라우저로 본다 (헤드리스 서버용)
python3 tools/silhouette_diff.py           # 실루엣이 정말 갈리는가 (실측)
python3 tools/face_diff.py --clip          # 얼굴이 역할을 나르는가 (실측)
python3 tools/focus_stack.py --all         # 초상 → ★1~★6 여섯 단계로 굽는다
python3 tools/focus_stack.py --boxes --pick # 얼굴 상자 · 종마다 대표 한 장
./pipeline3d/run.sh faces                  # 초상 78종 514장 생성 (SDXL, GPU)
```
