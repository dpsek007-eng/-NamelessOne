# 이렘의 탑 (Tower of Irem)

멸망한 세계가 탑의 형태로 남았다.
플레이어는 그 세계 바깥의 존재이고, 탑에 갇힌 죽은 자들을 불러내 함께 오른다.

모바일 방치형 수집 RPG · Unity 6 · 1부 100층

---

## 한 줄

> 플레이어는 이렘을 **구하러** 왔다고 믿는다.
> 그런데 탑이 보낸 신호는 구조 요청이 아니었다.

## 핵심 설계

| | |
|---|---|
| **등급 = 선명도** | 강함이 아니라 "탑이 얼마나 또렷하게 기억하는가" |
| **본디** | 숨겨진 성장 한계. ★1이 10성까지 갈 수도, ★5가 6성에서 멈출 수도 |
| **확률이지 약속이 아니다** | ★1은 ★6까지 갈 확률도, 가서 좋을 확률도 낮다 (0.35%). 태생 ★4는 쉽고 싸고 강하다 (23.2%) |
| **남은 버릇 5종** | ★6 특성이 고유가 아니면 역할 하나가 묻어온다 — 막아선 자국 · 쥐던 손 · 내민 손 · 뜬 눈 · 먼저 난 발자국. 굴리지 않고 **겹친 사람들의 다수결** |
| **초점** | 선명도를 문자 그대로 그림에 건다. ★1은 얼굴이 **없는** 게 아니라 **안 맞는다**. 각성할수록 맞아 간다 |
| **초반 상한** | 지금 열려 있는 선명도는 **★6 까지**. ★7~10은 아직 쓰이지 않은 문장이다 |
| **레벨** | 상한이 **도달 최고층**. 탑을 오르면 로스터 전체가 따라 오른다 |
| **겹치기** | 잔상을 겹쳐 기억 조각을 읽는다. 조각 5개 = 성급 +1. 흡수된 잔상의 스킬 하나가 남는다 |
| **개화** | 육성 방식에 따라 다른 스킬로 갈라진다. 늦개화 재능도 있다 |
| **뜰 (0층)** | 불러낸 잔상이 사는 곳. 생전의 생업을 그대로 한다 |
| **층 공략** | 모든 층에 최소 3가지 길. 약한 캐릭터로 푸는 길에 최고 보상 |
| **고유성** | 무명 잔상은 플레이어마다 다르게 생성된다 |

**오를수록 과거로 간다.** 1층이 멸망의 날, 100층이 세계의 시작.
위로 갈수록 세계가 아름다워지고, 그럴수록 무거워진다.

**몸집(macro)은 구워야 하고 자세(bones)는 안 구워도 된다.** 동작 네 벌이 뼈를 전부
절대값으로 찍으므로(`make_demo.py base_pose` — NLA 누수를 막으려고 그렇게 했다)
쉼자세를 굽어 놓아도 클립이 첫 프레임에 덮어쓴다. 그래서 자세는 클립이 끝난 **뒤에**
얹는 층이다 — 브라우저는 `mixer.update` 뒤(`viewer/garden.html`), 유니티는
`LateUpdate`(`ShadeView3D`). 적는 곳은 `data/shades.json` 한 벌이고,
근거(`src`)가 없는 몸은 `chars/src/shades.py` 가 받지 않는다.

시뮬레이터 실행:

```bash
python3 tools/bondi_sim.py      # 본디 분포·승급 비용
python3 tools/fusion_sim.py     # 승급 경제
python3 tools/gacha_sim.py      # 소환 확률
python3 tools/summon_value.py   # 소환 1회의 값 (조각 기준)
python3 tools/trait_odds.py     # ★6 특성이 고유일 확률
python3 tools/focus_curve.py    # 초점 곡선 (얼굴이 또렷해지는 속도)
python3 tools/pacing_sim.py     # 1막 페이싱
python3 tools/shade_gen.py 10   # 무명 잔상 생성
```

뜰(에이전트 23명)은 유니티 없이 돈다 — 도커의 dotnet SDK 로 실행한다:

```bash
docker run --rm -v "$PWD":/w -w /w mcr.microsoft.com/dotnet/sdk:8.0 \
  dotnet run --project Tools/GardenRunner -- garden 2000 42   # 뜰 2000걸음 (map · bonds 모드도 있다)
docker run --rm -v "$PWD":/w -w /w mcr.microsoft.com/dotnet/sdk:8.0 \
  dotnet run --project Tools/GardenRunner -- web 600 42        # 굽는다 → viewer/garden.json (브라우저가 재생할 사건 목록)
docker run --rm -v "$PWD":/w -w /w mcr.microsoft.com/dotnet/sdk:8.0 \
  dotnet run --project Tools/SyntaxCheck -- unity/Assets/Scripts   # 유니티 없이 문법만 본다
python3 tools/check_bonds_parity.py <C#출력>   # 인연이 파이썬과 글자까지 같은가
python3 tools/check_lines.py                   # 뜰 대사 497줄 검사 (실행 중에 API 를 부르지 않는다)
```

## 상태

- ✅ 1부 스토리 100층 전체
- ✅ 시스템 설계 12종 · 밸런스 검증
- ✅ 층 사양 60개 (1·2막, `data/floors.json` — 56개 층에 길이 여러 갈래)
- ✅ 캐릭터 23명 (`data/characters.json`) — 고유 특성이 쓰인 사람은 **11명**
- ✅ 잔상 23명이 에이전트로 도는 뜰 (`Irem.Sim` · 도커로 실측)
- ⬜ 고유 특성 남은 12명 (★1~3 무명·편린)
- ⬜ 3막·4막 층 사양 (61~100층) — 대본은 `docs/16` 에 있다
- ✅ 뜰을 브라우저에서 본다 (`viewer/garden.html` — 유니티 없이, 3D 몸·동작 그대로)
- ⬜ Unity 구현 — 3D 뜰·전투 층 코드는 있으나 **유니티가 이 서버에 없어 미검증**
  (`CLAUDE-HANDOFF.md` 13절). 유니티 자체를 브라우저에서 돌리는 WebGL 굽기 손잡이는
  있다 (`[이렘/웹으로 굽기]`) — 서버는 면허를 못 켜므로 허브가 있는 PC 에서 굽는다
