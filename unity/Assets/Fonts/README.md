# 폰트

- **NanumGothic.ttf** — 본문·수치
- **NanumMyeongjo.ttf** — 제목·잔상의 말

네이버 나눔글꼴. **SIL Open Font License 1.1** 로 배포된다.
게임에 넣어 재배포할 수 있고, 임베딩에 제한이 없다.
전문: https://scripts.sil.org/OFL

한글은 OS 폰트에 기대면 안 된다. 안드로이드·iOS 빌드에서는
그 폰트가 있으리라는 보장이 없다. 그래서 프로젝트에 넣는다.

TMP 폰트 에셋은 **[이렘 → 폰트 만들기]** 로 만든다. 동적(Dynamic) 방식이라
글리프를 미리 다 굽지 않고 쓰는 글자만 그때그때 아틀라스에 올린다.
