# 대본 샘플 — 톤 기준

세 장면으로 문체를 고정한다. 이후 모든 텍스트는 이 기준을 따른다.

## 문체 규칙

1. **짧은 문장.** 쉼표로 잇지 않는다
2. **감정을 설명하지 않는다.** 슬프다고 쓰지 않는다. 슬픈 것을 보여준다
3. **시스템 텍스트는 차갑게.** 감정은 캐릭터 대사에만 둔다
4. **정적을 쓴다.** `……` 는 아껴 쓰되, 쓸 때는 한 줄을 통째로 준다
5. **설명은 늦게.** 플레이어가 먼저 눈치채게 두고, 확인만 해준다

---

## 장면 1 — 프롤로그 (게임 시작)

일반적인 게임 부팅 화면처럼 시작한다. 로고도 없고 음악도 없다.

```
                    수신 대기 …


                    신호 도착

                    발신 : 확인 불가
                    거리 : 측정 불가
                    상태 : 손상됨


                    해석 중 ……


                    ▸  구해 달라


                    해석 완료
```

```
[화면이 밝아진다. 재가 덮여 있다. 아무것도 없다.]

여기서부터가 탑입니다.

당신은 들어올 수 없습니다.
부를 수는 있습니다.

부르면 옵니다.
아직 대답할 수 있는 사람이 남아 있습니다.
```

> **이 화면의 레이아웃을 그대로 저장해 둔다. 100층에서 재사용한다.**
> 폰트, 자간, 줄 간격까지 동일해야 한다. 다르면 효과가 반감된다.

## 장면 2 — 1막 전환점 (18층 전후 · 뜰)

플레이어가 뜰에 접속했을 때 발생한다. 강제 이벤트.

```
[화덕. 빵 서른일곱 개가 식어 있다.]

빵을 굽던 사람
    오늘도 서른일곱 개입니다.

    ……

    가지러 오는 사람이 없네요.

    다들 어디 갔습니까?
```

```
                ▸  말한다
                ▸  말하지 않는다
```

### 「말한다」

```
[플레이어의 말은 화면에 표시되지 않는다.]

빵을 굽던 사람
    아.

    ……

    ……

    그럼 서른일곱은 누구였습니까.

[정적]

    …기억이 납니다.

    마지막 사흘에는 아무도 오지 않았어요.
    알고 있었습니다.

    알면서 구웠습니다.
```

```
    ─ 각성 4가 강제로 열렸습니다
    ─ 이 잔상의 모든 대사가 바뀝니다
    ─ 되돌릴 수 없습니다
```

### 「말하지 않는다」

```
[아무 말도 하지 않는다.]

빵을 굽던 사람
    …좀 더 기다려 보겠습니다.

    아직 따뜻하니까요.
```

```
    ─ 이 잔상은 끝까지 알지 못한 채로 남습니다
    ─ 되돌릴 수 없습니다
```

> 어느 쪽도 정답이 아니다. **성능 차이를 두되, 어느 쪽이 유리한지 명시하지 않는다.**
> 알린 잔상은 강해지고, 알리지 않은 잔상은 뜰에서의 효율이 높다.

## 장면 3 — 100층

```
[아무것도 없다. 층이 아니라 여백에 가깝다.]
[이름 없는 자가 서 있다. 처음으로 플레이어 쪽을 보고 있지 않다.]

이름 없는 자
    여기까지 왔군요.

    ……

    나도 여기까지는 왔습니다.
```

```
    나는 당신 전에 대답한 사람입니다.
    내 앞에도 있었고, 그 앞에도 있었습니다.

    우리는 전부 같은 말을 들었습니다.
    전부 같은 선택을 했습니다.

    그래서 여기 있습니다.
```

이어서 프롤로그와 **완전히 동일한 화면**이 뜬다.

```
                    신호 재수신

                    상태 : 복구됨


                    해석 중 ……


                    ▸  기억해 달라


                    이전 해석 : 구해 달라

                    정정 사유 :
                    발신자는 구조를 요청한 적이 없습니다
```

```
[정적]

이름 없는 자
    이렘은 살아나고 싶다고 한 적이 없습니다.

    끝까지 세어 달라고 했습니다.
    한 사람도 빠뜨리지 말고.

    ……

    나는 그 말을 잘못 읽었습니다.
```

### 최종 선택

```
                ▸  되살린다
                ▸  끝맺는다
```

**되살린다**
```
[세계가 돌아온다. 짧게. 아름답게.]
[그리고 균열이 다시 열린다.]

탑에 한 겹이 더 쌓였습니다.

    ─ 명부 000번 옆에 새 항목이 추가되었습니다
    ─ 이름 없음
```

**끝맺는다**
```
명부를 엽니다.

[획득한 잔상의 이름이 하나씩 지나간다]
[이름이 남지 않은 잔상은 그들의 버릇으로 불린다]
[아직 만나지 못한 자리는 비어 있다]

    물통에 천을 감던 사람
    계단을 세며 오르던 사람
    세렌
    카브릴
    ─ 비어 있음 ─
    ─ 비어 있음 ─
    빵을 굽던 사람
    ...

이렘 명부 · 복원 {N}%

{N}%만큼의 사람이 이름을 되찾고 흐려졌습니다.
나머지는 이름 없이 끝났습니다.
```

> 엔딩 텍스트는 **플레이어의 실제 명부 데이터로 생성한다.**
> 미리 쓴 문장이 아니라 그 사람이 실제로 만난 사람들의 목록이어야 한다.
> 비어 있는 자리를 보여주는 것이 이 엔딩의 전부다.

---

## 앞으로 쓸 때

- 층 통과 텍스트는 **4문장을 넘기지 않는다**
- 잔상 대사에 느낌표를 쓰지 않는다. 이 세계에는 흥분할 일이 없다
- 시스템 메시지와 캐릭터 대사의 **서체를 다르게** 한다. 100층에서 그 대비가 무기가 된다
- 황금기 구간(61~80층)에서는 **아무것도 설명하지 않는다.** 풍경만 쓴다
