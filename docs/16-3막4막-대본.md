## 70층 · ★ 반전 2 — 이름 없는 자

```
그가 서 있다.

처음으로 당신 쪽을 보고 있지 않다.
```
```
이름 없는 자
    여기까지 왔군요.

    ……

    나도 여기까지는 왔습니다.
```
```
이름 없는 자
    나는 당신 전에 대답한 사람입니다.
    내 앞에도 있었고, 그 앞에도 있었습니다.

    우리는 전부 같은 말을 들었습니다.
    전부 같은 선택을 했습니다.

    그래서 여기 있습니다.
```
```
    ─ 각성 5가 열렸습니다
    ─ 명부 000번 : 이전에 응답한 자들
```

**복선 회수 확인**

| 심은 곳 | 내용 | 이제 밝혀지는 것 |
|---|---|---|
| 각성 1 | 늘 플레이어 쪽을 본다 | 자기 자리에 올 사람을 보고 있었다 |
| 각성 2 | 다른 잔상이 인식 못 한다 | 이렘 사람이 아니다 |
| 각성 3 | 선 자리는 사람이 죽은 자리 | 그가 실패한 자리들이다 |
| 각성 4 | 100층에도 있다 | 전부 거기까지는 갔다 |
| 3층 | 무료 지급, 육성 불가 | 플레이어의 자리였다 |

## 100층 · 실행

```
아무것도 없다.
층이 아니라 여백에 가깝다.

이름 없는 자가 서 있다.
```
```
이름 없는 자
    나는 되살리는 쪽을 골랐습니다.

    ……

    이렘은 한 번 더 살았습니다.
    그리고 한 번 더 죽었습니다.

    그게 내가 한 일의 전부입니다.
```
```
    75층에서 당신은 「{선택}」을 골랐습니다.

                ▸  그대로 한다
                ▸  바꾼다
```

### 되살린다

```
[세계가 돌아온다. 짧게. 아름답게.]
[종이 울린다. 여섯 시다.]
[균열이 다시 열린다.]
```
```
탑에 한 겹이 쌓였다.
```
```
    ─ 명부에 항목이 추가되었습니다
    ─ 000번 옆 · 이름 없음
```

### 끝맺는다

```
명부를 연다.
```
```
[획득한 잔상의 이름이 하나씩 지나간다]
[이름이 남지 않은 잔상은 그들의 버릇으로 불린다]

    물통에 천을 감던 사람
    계단을 세며 오르던 사람
    빵을 굽던 사람
    세렌
    카브릴
    북문의 수문장
    ─ 비어 있음 ─
    ─ 비어 있음 ─
    누군가의 어머니
    ...
```
```
이렘 명부 · 복원 {N}%

{N}%만큼의 사람이 이름을 되찾고 흐려졌습니다.
나머지는 이름 없이 끝났습니다.
```

> **엔딩 텍스트는 플레이어의 실제 명부 데이터로 생성한다.**
> 미리 쓴 문장이 아니라 그 사람이 실제로 만난 사람들의 목록이어야 한다.
> **비어 있는 자리를 보여주는 것이 이 엔딩의 전부다.**

"오를수록 과거로 간다"는 규칙이 1000층까지 그대로 유지된다.
각 세계는 자기 안에서 다시 아래=멸망, 위=시작을 갖는다.
