# 2막 대본 — 31~60층

**구간**: 붕괴기 후반(31~40) + 균열기(41~60)
**핵심 비트**: 38층 반복의 흔적 · 55층 탑의 정체

---

## 31~37층 · 종소리가 가까워진다 (붕괴기)

**31층**
```
전선이 여기서 멈췄다.
양쪽 다 더 나아가지 못했다.

이긴 쪽이 없다.
```

**32층**
```
깃발이 땅에 꽂혀 있다.
어느 쪽 것인지 알 수 없다.

색이 다 빠졌다.
```

**33층**
```
병사들의 이름이 벽에 적혀 있다.
세로로 길게, 빽빽하게.

아래로 갈수록 글씨가 급해진다.
```

**34층**
```
종소리가 들린다.
아직 멀다.

이 시대에는 아직 무너지지 않은 종이 있다.
```

**35층**
```
사람들이 위를 보고 있다.
전부 같은 방향이다.

종이 울리는 쪽이다.
```

**36층**
```
피난 행렬이 두 갈래로 갈라진다.
한쪽은 성으로, 한쪽은 종소리 쪽으로.

성으로 간 쪽의 발자국이 더 많다.
```

**37층**
```
종소리가 멈춘다.

행렬도 멈춘다.
```

## 38층 · ★ 반복의 흔적

```
벽에 표식이 있다.
26층에서 본 것과 같은 손이다.

세어 보았다.
```
```
표식은 당신이 오른 층수보다 많다.
```
```
누군가 여기까지 왔다.
그리고 여기서 멈추었다.

한 번이 아니다.
```
```
    ─ 기록이 갱신되었습니다
    ─ 「이번에도 같은 곳에서 멈추었다」
```

> **여기서 설명하지 않는다.** 표식이 여러 겹이라는 사실만 보여준다.
> 누가, 왜, 몇 번인지는 55층까지 미룬다.

## 41~45층 · 종탑 (균열기)

**41층** — 세렌 획득
```
서쪽 종탑이다.

밧줄에 천이 감겨 있다. 두껍게, 여러 겹으로.
계절마다 두께를 다르게 했다고 한다.

그는 아직 여섯 시가 오지 않았다고 믿는다.
```

**42층**
```
뜰의 종탑이 다시 섰다.

세렌이 종을 쳤다.
잔상들이 전부 하던 일을 멈췄다.

아무도 대피하지 않았다.
```

**43층**
```
종은 하루 두 번 울렸다.
아침 여섯 시와 저녁 여섯 시.

그 외에는 아무 일도 일어나지 않는 도시였다.
```

**44층**
```
도시 사람 대부분은 그의 이름을 몰랐다.

소리는 전부 알고 있었다.
```

**45층**
```
균열이 처음 열린 자리다.

폭은 사람 손바닥만 하다.
깊이는 재어 보지 못했다.
```

## 46~50층 · 여덟 번째 보고서

**46층**
```
왕립 기록관이다.

곡물 출납 장부가 벽 한 면을 채우고 있다.
숫자가 전부 맞다.
```

**47층** — 이델 획득
```
3급 서기다.

밤하늘의 자리를 적는 것이 취미였다고 한다.
어느 해부터 별이 조금씩 어긋났다.

그는 그것을 일곱 번 보고했다.
```

**48층**
```
반려 도장이 찍힌 종이가 쌓여 있다.
같은 필체가 일곱 장.

여덟 번째는 붉은 도장이 없다.
```

**49층**
```
여덟 번째 보고서의 마지막 문장은 끊겨 있다.

    그러므로 남은 시간은
```

**50층** — 이델 각성 5 연동
```
이델의 방은 무너지지 않았다.
사본이 아직 그 자리에 있다.
```
```
[사본을 펼친다]

[일곱 장은 그가 쓴 그대로다.]
[여덟 번째 장에 문장이 하나 늘어나 있다.]

    그러므로 남은 시간은
    ─ 이번에도 같은 곳에서 멈추었다
```
```
이델은 이 문장을 쓰지 않았다.
그가 죽은 뒤에 적힌 것이다.
```

> 이델 각성 5를 달성한 플레이어만 이 장면을 본다.
> **텍스트를 읽고 캐릭터를 키운 사람이 먼저 안다.** (`04-본디.md` 단서 원칙)

## 55층 · ★ 탑의 정체

```
층이 어긋나 있다.

바닥과 천장의 재질이 다르다.
이어 붙인 자리가 보인다.
```
```
이 층은 이렘이 만든 것이 아니다.
```
```
[표식이 있는 벽이 전부 드러난다]
[층마다 하나씩, 아래에서 위로]
[같은 손이 그은 것도 있고, 다른 손도 있다]

탑은 건물이 아니다.
```
```
되살리려 한 시도들이 한 겹씩 쌓인 것이다.

한 번 시도할 때마다 세계는 조금 더 과거로 되감겼다.
되감긴 만큼이 층이 되었다.
```
```
그래서 위로 갈수록 과거다.
그래서 위로 갈수록 아름답다.

당신이 지금까지 오른 것은
전부 누군가의 실패다.
```

> `07`~`13` 문서의 모든 설정이 여기서 하나로 묶인다.
> **"오를수록 아름다워진다"가 정서적 연출이 아니라 물리 법칙이었음이 밝혀지는 지점.**
