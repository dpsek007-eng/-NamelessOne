# 방치와 등반 — 무엇이 저절로 되고 무엇이 안 되는가

## 규칙

> **방치는 자원을 만든다. 층은 만들지 못한다.**
> 탑을 오르는 것은 언제나 플레이어가 직접 한다.

| | 방치 중 | 플레이어 접속 시 |
|---|---|---|
| 유품·기억 조각·진급석·울림 생산 | ⭕ 자동 | — |
| 뜰 생활, 인연 진행 | ⭕ 자동 | — |
| **기존 층 순회** (클리어한 층 반복) | ⭕ 자동 | — |
| 잔상 각성·개화·승급 | ❌ | ⭕ **수동** |
| **신규 층 등반** (미개척) | ❌ | ⭕ **수동** |

> **전진은 사람이 하고, 지나온 길은 저절로 돈다.**
> 새 층을 여는 것만 수동이다. 이미 연 층은 방치로 반복 파밍한다.

## 왜 이렇게 바꾸는가

원래 설계에는 모순이 있었다.

- `01-세계관.md` — **잔상은 자기가 죽은 층에서 벗어나지 못한다. 플레이어가 불러야 움직인다**
- `10-시스템-구조.md` — 방치 중에 층이 진행된다

앞뒤가 맞지 않았다. 잔상이 스스로 오를 수 있다면 애초에 플레이어가 필요 없다.

**바로잡은 규칙**

> 잔상은 스스로 오르지 못한다. 부르는 사람이 있어야 움직인다.
> 플레이어가 없는 동안 그들은 뜰에서 산다. 일하고, 기다린다.

이제 설정과 시스템이 일치한다.
**플레이어의 부재가 서사 장치이자 게임 규칙이 된다.**

## 산출원 둘 — 뜰과 순회

| | **뜰** | **층 순회** |
|---|---|---|
| 조건 | 잔상을 배치하면 된다 | **그 층 돌파 전투력의 1.2배 이상** |
| 성격 | 꾸준한 기본 산출 | 원하는 자원 집중 획득 |
| 선택 | 생업 배치 | **어느 층을 돌지 지정** |
| 대상 | — | 클리어한 **일반층**만 (연계·관문 제외) |

관문층을 순회에서 빼는 이유: 3팀 15명을 계속 묶어두면 나머지 운영이 마비된다.

### 순회 규칙

- 클리어한 일반층 중 **하나를 지정**해 반복한다
- 지정 층의 돌파 요구치 × **1.2 이상**이어야 자동으로 돈다. 아슬아슬하면 못 돈다
- 1회 = 3분. 12시간 상한이면 **240회**
- 층이 높을수록 회당 보상이 크다

### 시대마다 나오는 것이 다르다

| 시대 | 층 | 주 산출 |
|---|---|---|
| 종말기 | 1~20 | **유품** — 폐허에서 나온다 |
| 붕괴기 | 21~40 | **진급석** — 부서진 성벽과 무기에서 |
| 균열기 | 41~60 | **기억 조각** — 아직 기록이 남아 있다 |
| 황금기 | 61~80 | **울림** — 종이 아직 울리던 시절 |
| 여명기 | 81~99 | 전 자원 소량 + 고유 재화 |

**어느 층을 도느냐가 곧 무엇을 키우느냐가 된다.**
진급석이 급하면 붕괴기를, 개화 재료가 급하면 균열기를 돈다.
층을 올릴수록 파밍 선택지가 늘어나므로 등반 동기가 하나 더 생긴다.

## 뜰 산출물

생업마다 나오는 것이 다르다. 뜰 배치가 곧 자원 전략이 된다.

| 자원 | 쓰임 | 주 생산 생업 |
|---|---|---|
| **유품** | 각성 재료 | 담장 · 목공 · 채석 · 대장간 |
| **기억 조각** | 개화(스킬) 재료 | 서고 · 종탑 · 약방 |
| **진급석** | **승급 필수 재료** | 채석 · 대장간 |
| **울림** | 일반 소환 재화 | 종탑 · 등대 |

- 방치 상한 **12시간**. 그 이상은 쌓이지 않는다
- 상한은 하루 2회 접속 리듬을 만든다

## 진급석은 각성 단계마다 든다

`08-승급.md` 갱신: 성급은 겹치기로 직접 오르지 않는다. **각성 단계 하나하나에 진급석이 든다.**

```
각성 조각 + 진급석  →  각성 +1
각성 5단계          →  성급 +1
```

아래 표는 **성급 하나를 올리는 데 드는 총량**이다 — 그 안의 각성 5단계에 나뉘어 든다.
**나누는 비율은 균등하다** — 한 구간 안에서는 다섯 조각 값이 같고, 구간이 바뀔 때만 오른다
(`tools/pacing_sim.py`). 조각마다 값을 달리하면 「몇 번째 조각인가」를 UI가 또 설명해야 하는데,
플레이어가 실제로 판단하는 단위는 조각이 아니라 성급이다.

| 성급 | 진급석 (5단계 합) |
|---|---|
| 1 → 2 | 2 |
| 2 → 3 | 5 |
| 3 → 4 | 12 |
| 4 → 5 | 28 |
| 5 → 6 | 64 |
| 6 → 7 | 150 |
| 7 → 8 | 340 |
| 8 → 9 | 800 |
| 9 → 10 | 1,800 |

두 축이 모두 필요해진다.

- **잔상**은 소환으로 (`18-소환.md`) — 겹쳐서 각성 조각이 된다
- **진급석**은 방치로 (뜰 배치)

한쪽만 파도 안 된다. 뽑기만 돌려도 못 올리고, 방치만 해도 못 올린다.
진급석은 **성급 상승 속도를 조절하는 주 레버**다. 밸런싱이 어긋나면 여기부터 만진다.

⚠ 다만 **1막에서는 이 레버가 작동하지 않는다.** 시뮬레이션에서 진급석은 한 번도
막지 않았고 23일차에 3,300이 남아돌았다 (`21-페이싱.md`). 1막의 병목은 재화가 아니라
겹치기에 드는 **머릿수**다. 이 레버가 실제로 걸리기 시작하는 곳은 ★8 이후다.

### 이 표가 `04-본디.md` 의 곡선과 어긋나는 것에 대해

위 표는 성급마다 약 x2.3으로 오르고 `04-본디.md` 의 비용 곡선은 x1.35다.
한동안 어느 쪽으로 통일할지 열어 두었는데, **통일할 필요가 없었다.**
`tools/fusion_sim.py` 로 끝까지 계산해 보니 둘이 서로 다른 것을 재고 있다.

| | 무엇을 재는가 | ★5 출발 | ★1 출발 |
|---|---|---|---|
| 겹치기 (잔상) | 출발이 어디였나 | 84명 | 512명 (**608%**) |
| 진급석 | 어디까지 갔나 | 3,154 | 3,201 (**101%**) |

표가 가파른 덕분에 마지막 두 계단(800 + 1,800)이 총액의 81%를 먹고,
그래서 진급석 쪽에서는 출발 등급이 **지워진다.**

> 흐렸던 사람일수록 **겹칠 사람**이 많이 든다.
> 하지만 **또렷해지는 값**은 누구에게나 같다.

**위 표를 그대로 쓴다.** 정의는 `tools/power.py` 의 `STONE` 하나뿐이다.

### 초반 천장 ★6 — 이 레버는 아직 3.5%만 쓴다

지금 열려 있는 선명도 천장은 ★6 이다 (`04-본디.md`).
★6까지 드는 진급석은 **111**이고, 이는 ★10까지의 3,201 중 **3.5%**다.
표의 뒷줄(150 / 340 / 800 / 1,800)은 전부 아직 안 열린 문이다.

이 레버를 「주 레버」라 부르는 것은 여전히 맞지만, **지금은 손잡이만 달려 있는 상태**다.
초반 밸런싱을 여기서 만지려 하면 안 된다 — 만질 곳은 관문 요구 인원과 소환 획득률이다.

레벨은 이 레버에 걸리지 않는다. 레벨 상한은 **도달 최고층**이므로
(`02-캐릭터-시스템.md` 4-1), 방치로 층을 오르면 로스터 전체가 따라 오른다.
재화로 막는 축과 시간으로 여는 축을 분리해 둔다.

## 층은 반드시 사람이 조정한다

층 등반은 전부 수동이다. 자동 편성·자동 등반 기능을 넣지 않는다.

**신규 층에 한한다.** 이미 연 층은 자동 순회 대상이다.

| 단계 | 플레이어가 하는 일 |
|---|---|
| 1 | 층의 조건을 확인한다 (`06-층-공략.md`) |
| 2 | 팀을 편성한다. 일반 1팀, 연계 2팀, 관문 3팀 (`17-편성.md`) |
| 3 | 등반을 실행한다 |
| 4 | 결과를 보고 재편성한다 |

**편성 보조는 넣되 대신 해주지는 않는다.**

- ⭕ 조건 미달 표시 — 어느 팀이 왜 못 맞췄는지
- ⭕ 후보 추천 — 조건을 만족하는 잔상 목록
- ⭕ 잠금 — 특정 잔상 고정
- ❌ 자동 편성으로 신규 층 즉시 클리어
- ❌ 미개척 층 스킵 티켓

> 신규 층을 스킵하게 하는 순간 이 게임의 유일한 능동 행위가 사라진다.
> 반복 파밍은 순회가 담당하므로, 수동으로 남는 것은 **처음 한 번뿐**이다.

## 두 루프

```
   [방치 루프]                          [등반 루프]
   접속 안 함                            접속함
       │                                    │
   뜰이 자원을 만든다                  자원으로 잔상을 키운다
   + 지정한 층을 순회한다              각성 · 개화 · 승급
       │                                    │
       └──────────────┐        ┌────────────┘
                      ▼        ▼
                  편성하고 새 층을 연다   ← 사람만 할 수 있다
                         │
                  새 층 = 새 사람 = 새 이야기
                         │
                  순회 가능 층이 늘어난다 → 방치 산출 증가
```

방치는 **연료**, 등반은 **소비**다.
새 층을 열지 않으면 순회 대상이 늘지 않아 산출이 정체된다.
**방치만으로는 앞으로 나아가지 못한다.**

## 귀환 보고서 수정

`11-비트시트.md`의 보고서는 "몇 층까지 올랐다"가 아니라
**"뜰에서 무슨 일이 있었다"**를 적는다.

```
자리를 비우신 동안 ─ 8시간 21분

23층을 167번 돌았습니다.
진급석 118   유품 204   기억 조각 27   울림 9

빵을 굽던 사람이 오늘도 서른일곱 개를 구웠습니다.
카브릴이 뜰 입구에 서 있었습니다. 여덟 시간 동안.

24층은 그대로입니다.
```

마지막 줄이 중요하다. **지나온 층은 저절로 돌지만, 다음 층은 당신이 없으면 열리지 않는다.**
