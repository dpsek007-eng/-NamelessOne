## 발견 — 승급과 편성 인원이 충돌한다

첫 시뮬레이션에서 **8일간 완전 정체 후 11개 층 폭주**라는 최악의 곡선이 나왔다.

진단 결과 막힌 이유가 **전부 인원 부족**이었다. 전투력 부족은 단 한 번도 없었다.

원인:

> **승급은 2명 → 1명이므로 머릿수가 순감한다.**
> 가능한 승급을 전부 하면 로스터가 계속 반토막 나서, 관문층 인원을 영영 못 채운다.

승급 판단을 「앞으로 10층 안의 최대 편성 인원을 확보한 뒤에만」으로 바꾸자
중앙값이 16일 → 13일로 줄고 편차도 절반이 되었다.

### 이것은 시뮬레이션 버그이자 실제 게임의 딜레마다

시뮬레이션 AI가 멍청했던 것은 맞다. 하지만 **이 딜레마는 실제 플레이어도 겪는다.**

- 승급하면 강해지지만 머릿수가 줄어든다
- 관문층은 15명을 요구한다
- 잘못 승급하면 다음 관문에서 막힌다

**정보 없이는 함정이 된다.** 되돌릴 수 없는 선택이므로 더 위험하다.

### ⚠ 필수 UI 요구사항

승급 확인 창에 반드시 표시한다.

```
승급하면 잔상이 1명 줄어듭니다.

  현재 보유      15명
  승급 후        14명
  다음 관문(30층) 필요  15명   ← 부족

  이대로 승급하면 30층을 열 수 없습니다.
```

- 다음 관문의 요구 인원을 **항상** 노출한다
- 부족해지는 경우 명시적으로 경고한다
- 막지는 않는다. 플레이어가 알고 고르게 한다

`08-승급.md`의 「재료 자동 선택 기본값은 선택 안 함」 원칙과 같은 맥락이다.

관문 인원을 조정하면 플레이어의 로스터 규모가 직접 움직인다.

## 사용한 수치

| 항목 | 값 |
|---|---|
| 방치 상한 | 12시간 × 2회 접속 |
| 뜰 산출 (배치 1명당 시간당) | 유품 1.5 · 기억조각 0.8 · 진급석 0.5 · 울림 0.25 |
