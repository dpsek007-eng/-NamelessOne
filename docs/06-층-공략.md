# 층 공략 — 하나의 층, 여러 개의 답

## 원칙

**모든 층은 최소 세 가지 방법으로 통과할 수 있다.**

1. **돌파** — 전투력으로 찍어누른다. 항상 존재한다
2. **열쇠** — 특정 조건을 갖추면 전투력이 낮아도 통과한다
3. **묘수** — 더 어려운 조건. 최상급 보상

플레이어마다 로스터가 다르므로(`05-고유성.md`), 조건은 **특정 캐릭터가 아니라 속성**으로 건다.
무명 잔상도 생업·시대·역할을 가지므로 똑같이 열쇠가 될 수 있다.

> 돌파 경로가 항상 있어야 한다. 조건을 못 맞춘 플레이어가 **영구히 막히면 안 된다.**
> 대신 돌파는 비효율적이어야 한다 — 시간이 훨씬 오래 걸린다.

## 조건의 종류

| 종류 | 예시 | 의도 |
|---|---|---|
| **역할** | `수호` 2명 이상 | 조합 사고 유도 |
| **생업** | `담장` 또는 `대장간` 보유 | 뜰 시스템과 전투를 연결 |
| **시대** | 해당 층 출신 1명 이상 | *그 자리에 있었던 사람*의 가치 |
| **소수** | 3명 이하로 클리어 | 고성능 소수 정예 |
| **약체** | 평균 선명도 3 이하 | **약한 캐릭터로 푸는 길** |
| **기억** | 본디 도달자 1명 포함 | 장기 육성 보상 |

`약체` 조건이 이 게임에서 특히 중요하다.
★1~★2만으로 클리어하면 보상이 가장 크다. 저등급 잔상이 버려지지 않는다.

## 보상 차등

| 경로 | 보상 |
|---|---|
| 돌파 | 기본 |
| 열쇠 1개 | 기본 + 유품 |
| 열쇠 2개 이상 | 기본 + 유품 + **기억 조각** |
| 약체/소수 | **해당 층 무명 잔상 발견 확률 대폭 상승** |

핵심: 조건 클리어의 보상을 **전투력**이 아니라 **새로운 사람과의 만남**으로 준다.
그래야 "더 세지려고 푼다"가 아니라 "더 만나려고 푼다"가 된다.

## 예시 — 24층 「닫힌 성문」

붕괴기. 북문이 닫혀 있고, 문 바깥에 사람들이 있다.

| 경로 | 조건 | 서사 |
|---|---|---|
| 돌파 | 전투력 100% | 문을 부순다 |
| 열쇠 A | `수호` 2명 이상 · 전투력 60% | 둘이 문을 지탱하는 동안 통과 |
| 열쇠 B | 24층 출신 1명 · 전투력 45% | **배수로를 아는 사람이 있다** |
| 열쇠 C | 생업 `담장` 보유 · 전투력 55% | 담의 약한 지점을 안다 |
| 묘수 | 열쇠 B + 약체 · 전투력 30% | 이름 없는 사람들이 이름 없는 길로 빠져나간다 |

열쇠 B에서 `북문의 수문장`(★3)이 `카브릴`(★5)보다 유용하다.
앞서 정한 **"저등급 잔상은 자기가 죽은 층에서 가장 강하다"** 가 여기서 실제 규칙이 된다.

묘수 경로의 서사가 이 게임의 주제 그 자체다.

## 방치형과의 결합

방치 전투는 자동이지만, **편성은 플레이어가 한다.**

- 자동 진행은 `돌파` 경로만 시도한다 → 느리지만 언젠가 뚫린다
- 열쇠 경로는 플레이어가 직접 편성해야 발동한다
- 즉 **접속하면 훨씬 빨리 오른다.** 접속하지 않아도 막히지는 않는다

방치형의 편의성과 퍼즐의 능동성이 충돌하지 않는 지점이다.
