# 1막 대본 — 1~30층

**세계**: 중세. 기예는 있으나 크지 않다. 기술 수준은 석조 성벽·수차·유리 세공까지.
**worldId**: 1 (이렘)

> **기예의 규칙 — 있었다. 그러나 균열 앞에서는 아무것도 하지 못했다.**
> 마법사는 불을 손바닥만큼 피웠고, 정령술사는 드물게 대답을 들었고,
> 성녀는 손을 얹었다. 그 정도였다.
>
> 이 규칙이 이델의 보고서를 오히려 강하게 만든다.
> 그가 일곱 번 반려당한 이유는 **권위 있는 술사들이 「별것 아니다」라고 했기 때문**이다.
> 점성술사는 별의 어긋남을 「주기」라고 결론지었다.
>
> 멸망의 원인은 1부에서 끝까지 밝히지 않는다.

---

## 1~5층 · 첫 부름 (종말기)

**1층**
```
재가 무릎까지 쌓여 있다.
발자국이 남지 않는다. 재가 너무 가볍기 때문이다.

여기가 이렘의 마지막 날이다.
```

**2층**
```
집이 줄지어 서 있다. 지붕만 없다.
문은 전부 열려 있다.

닫고 갈 사람이 없었다.
```

**3층** — `이름 없는 자` 지급
```
층 한가운데에 누군가 서 있다.

부른 적이 없다.
```
```
    ─ 명부 000번에 기록되었습니다
    ─ 이름 : 비어 있음
```

**4층**
```
탑이 당신을 알아본다.

부르면 옵니다.
아직 대답할 수 있는 사람이 남아 있습니다.
```

**5층**
```
누군가 대답했다.

그는 자기가 어디에 있는지 안다.
언제인지는 모른다.
```

## 6~10층 · 뜰 (종말기)

**6층**
```
불러낸 잔상이 이 층을 떠나지 못한다.
발이 재에 붙어 있는 것처럼.

갈 곳이 필요하다.
```

**7층**
```
탑의 아래쪽에 층수가 붙지 않은 층이 있다.
1층보다 아래, 땅과 맞닿은 곳.

무너지지 않았다.
```

**8층** — 뜰 개방
```
평범한 하루가 통째로 남아 있다.
아무 일도 일어나지 않은 날이다.

여기서는 시간이 흐르지 않는다.
그래서 흐려지지 않는다.
```
```
    ─ 0층 「뜰」이 열렸습니다
```

**9층**
```
잔상 하나를 뜰에 두었다.

그는 곧바로 일을 시작했다.
누가 시키지 않았다.
```

**10층**
```
무너져 있던 것이 다시 서 있다.

지은 것이 아니다.
기억해낸 것이다.
```

## 11~18층 · 종말기의 사람들

**11층**
```
그릇이 놓여 있다. 두 개다.
하나는 비어 있고 하나는 채워진 채로 굳었다.
```

**12층**
```
누가 계속 무언가를 굽고 있다.

이 층에는 밀이 없다.
```

**13층** — 빵을 굽던 사람 획득
```
화덕 앞에 앉아 있다.
서른일곱 개를 세어 두었다.

값을 받지 않은 지 오래되었다고 한다.
```

**14층** — ★ **1막 전환점**
```
뜰에서 그가 당신을 부른다.
```
> 전체 장면은 `12-대본-샘플.md` 「장면 2」 참조.
> 선택: **말한다** / **말하지 않는다**. 되돌릴 수 없다.

**15층**
```
잔상들이 서로를 본다.

한 사람이 달라졌다는 것을 그들도 안다.
아무도 묻지 않는다.
```

**16층**
```
우물이 있다. 두레박이 내려간 채로 멈춰 있다.

줄이 끊어진 것이 아니다.
당길 사람이 없었을 뿐이다.
```

**17층**
```
누가 이름을 부르고 있다.
두 음절이다.

대답은 없다.
```

**18층** — 누군가의 어머니 획득
```
잔해 아래에서 웅크린 자세로 발견되었다.
무언가를 감싸고 있었다.

품 안은 비어 있었다.
처음부터 없었는지, 빠져나갔는지는 알 수 없다.
```

## 21~30층 · 성문 (붕괴기)

**21층**
```
불에 탄 것이 아니라 부서진 것들이 나온다.

여기서부터는 전쟁이다.
```

**22층**
```
길 위에 짐이 흩어져 있다.
무거운 것부터 순서대로.

멀리 갈수록 가벼운 것만 남는다.
```

**23층**
```
수레 한 대가 길을 막고 있다.
바퀴가 부러졌다.

돌아서 간 발자국이 많다.
```

**24층** — 배수로 · 열쇠 조건 층
```
북문이다. 닫혀 있다.

문 옆에 격자가 하나 있다.
사람 하나가 겨우 지나갈 크기다.
```
```
    ─ 이 층에는 네 가지 길이 있습니다
    ─ 조건을 갖추면 문을 부수지 않고 지날 수 있습니다
```
> `06-층-공략.md` 24층 사양 참조. 조건 클리어 시 `북문의 수문장` 획득.

**25층**
```
문 바깥이다.

여기 있던 사람들은 문이 닫히는 소리를 들었다.
```

**26층** — 반복의 흔적 (설명하지 않는다)
```
벽에 표식이 있다.
누가 지나가며 그은 것이다.

당신은 아직 이 층에 표식을 남긴 적이 없다.
```

**27층** — 카브릴 획득
```
문을 등지고 선 사람이 있다.

명령은 옳았다고 말한다.
세 번 말한다. 묻지 않았는데.
```

**28층** — ★ **1막 클라이맥스**
```
카브릴과 북문의 수문장을 같은 뜰에 두었다.
```
```
[뜰. 사흘이 지났다.]

[카브릴은 그를 피해 다녔다.]
[사흘째 되는 날, 수문장이 먼저 다가왔다.]

북문의 수문장
    대장님.

    ……

    그 명령은 옳았습니다.

[카브릴은 대답하지 않는다.]

북문의 수문장
    열한 명이 배수로로 나갔습니다.
    문을 열었으면 그 길도 막혔을 겁니다.

    ……

    저는 그걸 압니다.
    대장님은 모르셨을 뿐입니다.

[카브릴은 여전히 대답하지 않는다.]
[그리고 그 자리를 떠나지 않는다.]
```
```
    ─ 카브릴 각성 6단계가 열렸습니다
    ─ 두 잔상의 자취가 상승했습니다
```

**29층**
```
성문 안쪽이다.

사흘 동안 열리지 않았다.
안쪽에도 사람이 죽어 있다.
```

**30층** — 1막 종료
```
붕괴기의 한가운데다.
아직 절반도 오르지 않았다.

위쪽 층에서 종소리가 들린다.
이 시대에는 아직 무너지지 않은 종이 있다.
```

## 귀환 보고서 샘플

방치 후 접속 시 표시된다. **이야기의 상당량을 여기서 흘린다.**

**초반형 (1~10층대)**
```
자리를 비우신 동안 ─ 6시간 12분

잔상들이 12층까지 올랐습니다.
빵을 굽던 사람이 화덕에 불을 올렸습니다.

아무도 먹지 않았습니다.
```

**14층 「말한다」 이후**
```
자리를 비우신 동안 ─ 9시간 3분

빵을 굽던 사람이 오늘은 굽지 않았습니다.
화덕 앞에 앉아 있었습니다.

내일은 다시 구울 것 같습니다.
```

**28층 이후**
```
자리를 비우신 동안 ─ 7시간 41분

잔상들이 26층에서 세 번 물러섰습니다.
카브릴이 네 번째에 앞에 섰습니다.

수문장이 뒤에 있었습니다.
```

> 보고서는 **템플릿 + 실제 상태**로 생성한다. 미리 쓴 문장을 돌려쓰면 금방 들킨다.
> 편성·진행·인연 상태를 읽어 조합하는 방식으로 만든다.

## 1막 집필 규칙

- 층 통과 텍스트는 **4문장 이하**
- 느낌표 금지
- **설명하지 않는다.** 19층의 "멸망은 위에서 내려온 것이 아니었다" 정도가 상한선
- 26층 표식은 **절대 설명하지 않는다.** 38층에서 회수한다
- 20층 칼자국처럼 **사물로 말한다.** 사람을 등장시키지 않고도 사람이 있었음을 보여준다
