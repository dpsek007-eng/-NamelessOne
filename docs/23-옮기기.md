무거운 중간물은 **안 넣었다**:
`pipeline3d/out/mesh` (959M, TripoSR 원본 OBJ — 02 의 GLB 가 이걸 거친 결과다),

mesh 를 다시 만들려면 GPU 가 필요하다. **소품을 다시 굽을 일이 있으면 mesh 도 같이 옮겨라.**

## 푸는 법

    tar xf 00 은 없다. 저장소는 이렇게 연다:
    git clone 00-저장소.bundle TOP
    cd TOP && git checkout main

    tar xf ../01-초상.tar      -C pipeline3d/out
    tar xf ../02-소품.tar      -C pipeline3d/out
    tar xf ../03-소품이미지.tar -C pipeline3d/out
    tar xf ../04-역할실험.tar   -C pipeline3d/out
    tar xf ../05-캐릭터.tar     -C .
    tar xf ../06-초점.tar       -C .

    sha256sum -c 체크섬.txt     # 옮긴 뒤에 반드시

## 새 컴퓨터에 있어야 하는 것

  · **Blender 5.2.1 LTS + MPFB 애드온** — 몸·옷·동작이 전부 여기서 나온다. CPU 로 돈다.
    도커에 안 넣었다. snap 으로 깔았다.
  · python3 + PIL + numpy (자 재는 도구들)
  · GPU 는 **없어도 된다**. 위 tar 들이 GPU 산출물을 이미 담고 있다.
    다시 뽑을 일이 생기면 그때 필요하다 (`pipeline3d/run.sh`, 도커 이미지 두 개).
