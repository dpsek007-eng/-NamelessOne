# 캐릭터 — 몸과 옷

무명 잔상은 손으로 그리지 않는다. `docs/22-아트.md` 의 조합 구조를 그대로 메시로 옮긴다.

    체형(역할 5) → 의복(계층 11) → 소품(생업 47) → 강조색 → 흐려짐

블렌더 안에서 MPFB2 로 만든다. 옷은 새로 모델링하지 않고 MPFB 가 옷 맞추라고
넣어 둔 케이지(`helper-tights` 2,674정점 · `helper-skirt` 720정점)를 깎아서 쓴다.
그 케이지는 이미 뼈 웨이트가 100% 칠해져 있어서, 깎기만 하면 스키닝이 따라온다.

## 돌리는 법

    blender --background --python chars/src/make_bodies.py   -- --out chars/out/bodies
    blender --background --python chars/src/make_garments.py -- --out chars/out/garments \
                                                                --shots chars/out/garments/shots
    python3 chars/src/sheet.py

`--roles guard` / `--classes 귀족` 로 한 칸만 돌릴 수 있다. 값을 만질 때는 이쪽이 맞다 —
55벌은 한 번에 25분쯤 걸린다.

## 낸 것

| | 개수 | 정점 | 뼈 |
|---|---|---|---|
| `out/bodies` | 5 | 13,380 | 53 |
| `out/garments` | 55 (5×11) | 2,500~7,500 | 53 |

뼈대는 MPFB 내장 `game_engine` 하나를 다섯이 같이 쓴다. 뼈 이름이
`pelvis`/`spine_01`/`upperarm_l` … 라서 유니티 휴머노이드가 그대로 읽고,
Avatar 리타기팅으로 애니메이션 한 벌을 55벌이 나눠 쓴다.
옷은 몸과 같은 뼈대에 물려 있으므로 유니티에서는 옷의 SkinnedMeshRenderer 를
몸의 본에 다시 붙이면 된다.

머티리얼은 두 칸이다. 0번이 천(짙은 실루엣), 1번이 강조색.
강조색 면은 계층별 띠 높이(`garments.py: ACCENT`)로 정해진다 —
왕실·귀족은 어깨 장식, 성직·관리·상인·장인은 허리, 병졸은 흉갑선.
강조색이 없는 네 계층(술사·농어민·하인·유랑)은 머티리얼이 한 칸만 나간다.

## 눈으로 확인하는 것이 검사다

`--shots` 를 주면 정사영 정면 실루엣 PNG 가 같이 나오고, `sheet.py` 가
행=체형 열=계층 으로 붙여 준다. 이 단계에서 조용히 실패한 것이 세 번 있었다.

1. **체형이 셰이프키로만 남아 나갔다.** 다섯 GLB 의 부피가 208.9L 로 소수점까지
   같았다. 유니티는 모프 가중치를 0 으로 읽으므로 다섯이 전부 같은 몸이 된다.
   → `bake_shape()` 로 굽는다.
2. **뼈대가 몸에 안 맞았다.** 다섯 다 head 뼈가 `(0.000, -0.044, 0.697)` 였다.
   MPFB 는 이름에 `joint` 가 든 버텍스그룹으로 뼈 위치를 잡는데, 그 그룹은
   `detailed_helpers=True` 일 때만 생긴다. → 헬퍼를 켜고 `refit` 뒤에 굽는다.
3. **옷 일곱 모양 중 두셋만 갈렸다.** 2D 규격에서 밑단만 옮겼기 때문이다.
   후드는 두피에 가까웠고, 망토는 등 뒤에만 있어 정면에 안 보였고, 병졸의
   갑옷은 밑단이 tunic 과 0.019 밖에 차이가 안 났다. → 소매 드레이프,
   어깨 갑옷, 어깨 덮개 달린 두건, 한쪽 어깨가 드러난 유랑을 더했다.

셋 다 파일 크기나 정점 수로는 정상으로 보였다. 재거나 봐야 잡힌다.
